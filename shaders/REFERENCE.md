## Blend

### Blend Modes

`CyberMushroom/Blend/BlendModes.*`

Thirteen Photoshop blend modes against whatever Fusion has already drawn behind the object. Fusion's built-in ink effects stop at Add and Subtract - this is the rest of them.

Needs the background texture: put the object on a layer with something behind it, or the effect has nothing to read.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Mode | int | 2 | 0 .. 12 | 0 normal, 1 add, 2 multiply, 3 screen, 4 overlay, 5 soft light, 6 hard light, 7 difference, 8 lighten, 9 darken, 10 colour dodge, 11 colour burn, 12 exclusion. |
| Opacity | float | 1.0 | 0 .. 1 | How much of the blend to apply. |

**How to drive it:** Set Mode once in the object's properties. Screen (3) over a dark scene is a light shaft; Multiply (2) is a shadow or a stain; Overlay (4) is a colour wash that keeps the scene's contrast.

> Needs something drawn behind it. On an empty layer the background is blank and most modes will do nothing visible.

### Refract

`CyberMushroom/Blend/Refract.*`

Bends the background as it passes through the object, using the object's own shading as the lens. Draw a bubble, a bottle, a heat pocket or a pane of glass, apply this, and the world behind it warps.

Needs the background texture: put the object on a layer with something behind it, or the effect has nothing to read.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Tint Colour | color | 16777215 (RGB 255, 255, 255) |  | Colour the refracted background is stained with. |
| Strength | float | 16.0 | -128 .. 128 | How far the background is pushed, in texels. Negative bends the other way. |
| Magnify | float | 0.0 | -1 .. 1 | Scales the background inside the lens. Positive magnifies, negative shrinks. |
| Tint | float | 0.15 | 0 .. 1 | How strongly the tint colour stains what shows through. |
| Keep Sprite | float | 0.15 | 0 .. 1 | How much of the object's own art stays visible on top of the refraction. 0 is invisible glass. |

**How to drive it:** Draw the lens shape with soft shading - the shader reads the slope of the brightness, so a smooth dome bends more at its edges than in the middle, exactly like real glass.

> Needs something drawn behind it, on a lower layer or earlier in the same one.

### Stencil Clip

`CyberMushroom/Blend/StencilClip.*`

Shows the object only where the background behind it is a particular colour. Paint a mask colour into your level art and sprites will only draw inside it - water that only fills the pool, light that only lands on the floor, a reflection that stops at the edge of the puddle.

Needs the background texture: put the object on a layer with something behind it, or the effect has nothing to read.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Stencil Colour | color | 16711935 (RGB 255, 0, 255) |  | The background colour the object is allowed to draw over. Default is magenta, the traditional 'this is not real art' colour. |
| Tolerance | float | 0.1 | 0 .. 1.8 | How close the background has to be to the stencil colour. 0 is an exact match. |
| Softness | float | 0.05 | 0 .. 1 | Fades the clip out past the tolerance instead of cutting hard. |
| Invert | bool | 0 |  | On draws everywhere except over the stencil colour. |

**How to drive it:** Pick a colour that appears nowhere else in your art, put it on a lower layer, and set Tolerance just high enough to catch it.

> Needs something drawn behind it, on a lower layer or earlier in the same one.

## Blur

### Blur

`CyberMushroom/Blur/Blur.*`

A round, single-pass blur. Alpha-weighted, so blurring a sprite does not drag dark fringes out of its transparent edges the way a naive blur does.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Radius | float | 4.0 | 0 .. 64 | Blur radius in texels. |
| Quality | float | 2.0 | 1 .. 3 | Rings of samples: 1 is 9 taps and fine for small radii, 3 is 25 taps and stays smooth at large ones. |
| Amount | float | 1.0 | 0 .. 1 | Blends the blurred result back over the sharp original. |

**How to drive it:** Blur a copy of the background behind a pause menu, or ramp Radius up on a layer to pull focus.

> An object can only blur its own image, so the blur stops at the edge of the sprite. On a layer it has the whole frame to work with.

### Motion Blur

`CyberMushroom/Blur/MotionBlur.*`

Smears the image along a line. Point it the way the object is travelling and a fast sprite reads as fast instead of teleporting between frames.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Distance | float | 8.0 | 0 .. 128 | Length of the smear in texels. |
| Angle | float | 0.0 | 0 .. 360 | Direction of the smear in degrees. 0 is to the right, 90 is up. |
| Trailing | bool | 1 |  | On smears only behind the object, like a real trail. Off smears both ways, which is what a camera shutter does. |
| Amount | float | 1.0 | 0 .. 1 | Blends the smear back over the sharp original. |

**How to drive it:** Set Angle from the object's own direction and drive Distance from its speed, so the smear grows with the movement.

### Radial Blur

`CyberMushroom/Blur/RadialBlur.*`

Blurs outward from a point, or around it. Zoom for a dash or a hit, spin for a dizzy spell or a spinning pickup.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Centre X | float | 0.5 | -1 .. 2 | Point the blur radiates from, across the object. |
| Centre Y | float | 0.5 | -1 .. 2 | Point the blur radiates from, down the object. |
| Zoom | float | 0.1 | -1 .. 1 | Smear toward or away from the centre. Negative pulls inward. |
| Spin | float | 0.0 | -1 .. 1 | Smear around the centre instead. Positive and negative spin opposite ways. |
| Clear Centre | float | 0.0 | 0 .. 1 | Keeps the middle sharp out to this radius, so a character at the centre of a dash stays readable. |
| Amount | float | 1.0 | 0 .. 1 | Blends the blurred result back over the sharp original. |

**How to drive it:** Spike Zoom to 0.2 for three frames when the player dashes, then ease it back to 0.

## Color

### Adjust

`CyberMushroom/Color/Adjust.*`

Brightness, contrast, saturation and gamma in one pass. Reach for this before stacking three effects on an object, since each extra effect is another draw.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Brightness | float | 0.0 | -1 .. 1 | Added to every channel. 0 is no change. |
| Contrast | float | 1.0 | 0 .. 4 | Pushes colours away from mid grey. 1 is no change, 0 flattens to grey. |
| Saturation | float | 1.0 | 0 .. 4 | 1 is no change, 0 is greyscale, above 1 oversaturates. |
| Gamma | float | 1.0 | 0.1 .. 4 | Lifts or crushes the midtones without clipping the ends. 1 is no change. |

**How to drive it:** Everything defaults to "no change", so a freshly applied Adjust looks like nothing happened. That is deliberate.

### Colour Key

`CyberMushroom/Color/ColorKey.*`

Makes one colour transparent. For sprite sheets exported without alpha, for punching a window out of a backdrop, and for cutting a hole in anything at runtime.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Key Colour | color | 16711935 (RGB 255, 0, 255) |  | The colour to remove. Default is magenta. |
| Tolerance | float | 0.15 | 0 .. 1.8 | How close a pixel has to be to the key colour to be removed. |
| Softness | float | 0.05 | 0 .. 1 | Fades pixels out near the edge of the tolerance rather than cutting them hard. |
| Despill | float | 0.0 | 0 .. 1 | Pulls the key colour back out of the pixels that survive, which kills the coloured fringe left around a cut-out. |

**How to drive it:** Set Tolerance to 0 first and raise it until the whole area goes, then add Softness to clean up anti-aliased edges.

### Colour Replace

`CyberMushroom/Color/ColorReplace.*`

Swaps one colour in a sprite for another, within a tolerance. The palette-swap workhorse: one mushroom sheet, every mushroom in the game.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Find Colour | color | 255 (RGB 255, 0, 0) |  | The colour to look for. Pick it with the eyedropper from your actual sprite; anti-aliased edges will need some tolerance. |
| Replace With | color | 16711680 (RGB 0, 0, 255) |  | The colour it becomes. |
| Tolerance | float | 0.1 | 0 .. 1.8 | How far a pixel can sit from Find Colour and still count. 0 is an exact match. |
| Edge Softness | float | 0.05 | 0 .. 1 | Fades the swap out past the tolerance so anti-aliased edges do not turn into a hard rim. |
| Keep Shading | bool | 0 |  | On, the replacement keeps the original pixel's light and shade, which holds up on shaded sprites. |

**How to drive it:** Tolerance is a straight RGB distance, so start at 0.05 and raise it until the whole shape is caught but nothing else is.

### Gradient Map

`CyberMushroom/Color/GradientMap.*`

Throws away the hue and re-colours the sprite by brightness across four stops. This is how you get a whole scene onto one palette in a single pass: the defaults are already the DMG greens, darkest to lightest.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Stop 1 (darkest) | color | 997391 (RGB 15, 56, 15) |  | Colour for the darkest pixels. Default is DMG 15,56,15. |
| Stop 2 | color | 3170864 (RGB 48, 98, 48) |  | Colour for the dark midtones. Default is DMG 48,98,48. |
| Stop 3 | color | 1027211 (RGB 139, 172, 15) |  | Colour for the light midtones. Default is DMG 139,172,15. |
| Stop 4 (lightest) | color | 1031323 (RGB 155, 188, 15) |  | Colour for the brightest pixels. Default is DMG 155,188,15. |
| Offset | float | 0.0 | -1 .. 1 | Slides every pixel up or down the ramp. Negative darkens the whole image. |
| Contrast | float | 1.0 | 0 .. 4 | Widens or narrows the brightness range before it hits the ramp. |
| Amount | float | 1.0 | 0 .. 1 | Blends the mapped colour back over the original. |

**How to drive it:** Animate Offset to make a scene sink toward its dark stop for a dusk or damage state.

### Grayscale

`CyberMushroom/Color/Grayscale.*`

Drains the colour out of a sprite or a whole layer. Four weightings, because "grey" is not one thing: Rec.601 luminance is what your eye reads, plain average is what most pixel art was drawn against.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Amount | float | 1.0 | 0 .. 1 | 0 is the original, 1 is fully grey. |
| Mode | int | 0 | 0 .. 3 | 0 luminance (Rec.601), 1 flat average, 2 lightness (max and min averaged), 3 brightest channel. |

**How to drive it:** Put it on a layer with Amount on an alterable value to grey out the world behind a pause menu.

### Hit Flash

`CyberMushroom/Color/HitFlash.*`

The damage flash. Drives the sprite to a solid colour and back without touching its silhouette, so a hit reads instantly even at 160x144.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Flash Colour | color | 16777215 (RGB 255, 255, 255) |  | Colour the sprite flashes to. White for a generic hit, red for damage taken, dark green to read on a DMG screen. |
| Amount | float | 1.0 | 0 .. 1 | How far through the flash you are. Animate this, leave everything else alone. |
| Additive | bool | 0 |  | On, the colour is added on top so bright pixels blow out. Off, the sprite is blended toward the colour. |
| Alpha Fade | float | 0.0 | 0 .. 1 | Fades the sprite out as it flashes. Handy for death pops: run Amount and this together. |

**How to drive it:** On hit, set Amount to 1 and subtract ~0.15 from it every tick until it reaches 0. Six frames is about right for a pixel game.

### Hue Shift

`CyberMushroom/Color/HueShift.*`

Rotates the hue of every pixel, with saturation and value on the side. One sprite sheet, a dozen palettes: recolour enemies, pickups and player variants at runtime instead of drawing them twice.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Hue | float | 0.0 | -1 .. 1 | Hue rotation. 0 is no change, 0.5 is the opposite side of the wheel, 1 is a full turn. |
| Saturation | float | 1.0 | 0 .. 4 | Multiplies saturation. 1 is no change. |
| Value | float | 1.0 | 0 .. 4 | Multiplies brightness. 1 is no change. |
| Amount | float | 1.0 | 0 .. 1 | Blends the recoloured pixel back over the original. |

**How to drive it:** Hue is a full turn from 0 to 1, so animating it from 0 upward cycles the rainbow. Add 0.01 a tick for a slow shimmer.

### Invert

`CyberMushroom/Color/Invert.*`

Photo-negative. Cheap, loud, and reads through anything: a good one-frame hit stinger, a "wrong answer" blink, or a hazard that should never be mistaken for scenery.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Amount | float | 1.0 | 0 .. 1 | 0 is the original, 1 is fully inverted, 0.5 is flat grey. |
| Luminance Only | bool | 0 |  | On, only the brightness flips and the hue survives. Off, every channel flips. |

**How to drive it:** Toggle Amount between 0 and 1 every other frame for a strobe.

### Posterize

`CyberMushroom/Color/Posterize.*`

Snaps every channel to a fixed number of steps. Four levels is roughly what an 8-bit console gave you; two is a woodcut. Pair it with Dither if the banding gets ugly.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Levels | float | 4.0 | 2 .. 32 | Steps per channel. 2 is one bit per channel, 4 gives the classic retro banding. |
| Amount | float | 1.0 | 0 .. 1 | Blends the banded result back over the original. |
| Luminance Only | bool | 0 |  | On, only brightness is stepped and the hue stays smooth. Off, each channel is stepped on its own. |

**How to drive it:** Drop Levels from 32 toward 2 over a second for a "signal degrading" transition.

### Threshold

`CyberMushroom/Color/Threshold.*`

Two colours, one cut-off. Everything brighter than the threshold becomes the light colour, everything darker becomes the dark one. A 1-bit look for title cards, silhouette puzzles and stark flash frames.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Dark Colour | color | 997391 (RGB 15, 56, 15) |  | Colour for pixels below the cut-off. |
| Light Colour | color | 1031323 (RGB 155, 188, 15) |  | Colour for pixels above the cut-off. |
| Cutoff | float | 0.5 | 0 .. 1 | The brightness that splits dark from light. |
| Softness | float | 0.02 | 0 .. 1 | Width of the fade across the cut-off. 0 is a hard edge and will alias on a diagonal. |
| Amount | float | 1.0 | 0 .. 1 | Blends the result back over the original. |

**How to drive it:** Sweep Cutoff from 0 to 1 to dissolve an image from all-light to all-dark without touching its alpha.

### Tint

`CyberMushroom/Color/Tint.*`

Pushes the sprite toward a flat colour without touching its alpha. The everyday one: team colours, poison green, frozen blue, a dimmed-out menu item.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Colour | color | 16777215 (RGB 255, 255, 255) |  | The colour to tint toward. Fusion stores colours as BGR, the build script prints the RGB reading in shaders/REFERENCE.md. |
| Amount | float | 1.0 | 0 .. 1 | 0 leaves the sprite alone, 1 replaces its colour completely. |
| Keep Shading | bool | 1 |  | On, the tint keeps the sprite's own light and shade. Off, it flattens to one colour. |

**How to drive it:** Animate Amount from 0 to 1 with Set effect parameter.

## Distort

### Heat Haze

`CyberMushroom/Distort/HeatHaze.*`

Soft rising noise that bends the image, the air over a fire or a desert floor. Unlike Wave this has no repeating pattern, so it holds up over a whole screen.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Strength | float | 2.0 | 0 .. 32 | How far pixels move, in texels. |
| Cell Size | float | 24.0 | 1 .. 256 | Size of one noise cell in texels. Small is a fine shimmer, large is slow rolling air. |
| Rise Speed | float | 1.0 | -8 .. 8 | How fast the haze climbs when Time is animated. |
| Time | float | 0.0 | 0 .. 100000 | Animate this or the haze stands still. |
| Vertical Bias | float | 0.6 | 0 .. 1 | 0 wobbles evenly in both directions, 1 mostly pushes pixels up and down like rising air. |

**How to drive it:** Apply to a layer above the heat source, or to a tall invisible Active object with "apply to background" so only the air above the lava wobbles. Animate Time every tick.

### Shockwave

`CyberMushroom/Distort/Shockwave.*`

An expanding ring that bends whatever it passes over. The explosion effect: pair it with a white flash and a screen shake and a small hit turns into an event.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Centre X | float | 0.5 | 0 .. 1 | Centre of the ring across the object, 0 is the left edge and 1 the right. |
| Centre Y | float | 0.5 | 0 .. 1 | Centre of the ring down the object. |
| Radius | float | 0.3 | 0 .. 2 | Current size of the ring, where 1 is half the object's width. Animate this. |
| Ring Width | float | 0.1 | 0.01 .. 1 | How thick the disturbed band is. |
| Strength | float | 8.0 | -64 .. 64 | How far the ring pushes pixels, in texels. Negative pulls inward. |
| Highlight | float | 0.2 | 0 .. 2 | Brightens the crest of the ring so it reads even against flat colour. |

**How to drive it:** Apply to a layer. On the explosion, set Radius to 0 and add about 0.04 to it every tick until it passes 1.5, easing Strength down to 0 as it goes.

### Swirl

`CyberMushroom/Distort/Swirl.*`

Twists the image around a point, hardest in the middle and fading to nothing at the edge of its radius. Portals, whirlpools, drains, and a very good "sucked into the pipe" transition.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Centre X | float | 0.5 | 0 .. 1 | Centre of the twist across the object. |
| Centre Y | float | 0.5 | 0 .. 1 | Centre of the twist down the object. |
| Angle | float | 180.0 | -1440 .. 1440 | Degrees of twist at the centre. |
| Radius | float | 0.5 | 0.01 .. 2 | How far the twist reaches, where 1 is half the object's width. |
| Clip Edges | bool | 1 |  | On hides pixels dragged in from outside the object's image. |

**How to drive it:** Ramp Angle from 0 to about 720 over half a second while pulling Radius down, and the object screws itself out of existence.

### UV Transform

`CyberMushroom/Distort/UVTransform.*`

Scrolls, scales and rotates the image inside the object without moving the object. This is how you get endless parallax skies, conveyor belts, flowing lava and spinning gears out of one static Active object.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Scroll X | float | 0.0 | -1000 .. 1000 | Horizontal scroll, where 1 is the full width of the image. |
| Scroll Y | float | 0.0 | -1000 .. 1000 | Vertical scroll, where 1 is the full height. |
| Scale X | float | 1.0 | 0.01 .. 64 | Horizontal zoom. Above 1 shows more of the image, below 1 zooms in. |
| Scale Y | float | 1.0 | 0.01 .. 64 | Vertical zoom. |
| Angle | float | 0.0 | -1440 .. 1440 | Rotation in degrees around the pivot. |
| Pivot X | float | 0.5 | 0 .. 1 | Point the rotation and scaling happen around, across the object. |
| Pivot Y | float | 0.5 | 0 .. 1 | Point the rotation and scaling happen around, down the object. |
| Wrap Mode | int | 0 | 0 .. 2 | 0 wrap (tiles forever), 1 clamp (edge pixels smear), 2 clip (anything outside disappears). |

**How to drive it:** Add a small amount to Scroll X every tick for a conveyor. Set Wrap Mode to Wrap and the image tiles forever.

### Water Reflection

`CyberMushroom/Distort/WaterReflection.*`

Flips the image, ripples it and fades it out with depth. Put a copy of your scenery below the waterline, apply this, and it reflects.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Water Colour | color | 3170864 (RGB 48, 98, 48) |  | Colour the reflection is tinted toward. Default is DMG 48,98,48. |
| Ripple Size | float | 1.5 | 0 .. 32 | How far the ripples push pixels sideways, in texels. |
| Ripple Count | float | 6.0 | 0 .. 64 | How many ripples fit down the reflection. |
| Speed | float | 1.5 | -32 .. 32 | How fast the ripples travel when Time is animated. |
| Time | float | 0.0 | 0 .. 100000 | Animate this to make the water move. |
| Tint | float | 0.35 | 0 .. 1 | How strongly the water colour stains the reflection. |
| Depth Fade | float | 0.6 | 0 .. 1 | How much the reflection fades out toward the bottom, which is where it is furthest from the surface. |
| Flip | bool | 1 |  | On mirrors the image vertically, which is what you want when the source is the scenery above. Off leaves it upright. |

**How to drive it:** Duplicate the backdrop under the water, apply the effect to the copy, and animate Time. Fade Strength controls how fast the reflection dies off with distance from the surface.

### Wave

`CyberMushroom/Distort/Wave.*`

Runs a sine wave through the image. Underwater levels, heat shimmer, a wobbling menu, a flag - one shader, four jobs.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Amplitude | float | 2.0 | 0 .. 64 | How far pixels move, in texels. |
| Frequency | float | 3.0 | 0 .. 32 | How many waves fit across the object. |
| Speed | float | 2.0 | -32 .. 32 | How fast the wave travels when Time is animated. |
| Time | float | 0.0 | 0 .. 100000 | Animate this to move the wave. |
| Vertical | bool | 0 |  | Off pushes pixels sideways (a flag or a heat wobble). On pushes them up and down (a wave rolling across water). |
| Clip Edges | bool | 1 |  | On hides pixels pushed outside the object's image. Off smears the edge pixels instead, which suits a full-screen wobble. |

**How to drive it:** Add a little to Time every tick and the wave travels. Leave Time alone and you get a fixed bend.

## Light

### Radial Light

`CyberMushroom/Light/RadialLight.*`

Turns a plain rectangle into a light: a soft radial pool of colour, or - with Invert on - a sheet of darkness with a hole cut in it. Two objects and this shader give you a whole lighting system without an extension.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Colour | color | 16777215 (RGB 255, 255, 255) |  | Light colour with Invert off, darkness colour with it on. |
| Centre X | float | 0.5 | -1 .. 2 | Centre of the light across the object. |
| Centre Y | float | 0.5 | -1 .. 2 | Centre of the light down the object. |
| Radius | float | 0.5 | 0 .. 2 | How far the light reaches, where 1 is the edge of the object. |
| Falloff | float | 2.0 | 0.1 .. 8 | How quickly it fades. 1 is a straight ramp, higher values keep a bright core with a fast edge. |
| Intensity | float | 1.0 | 0 .. 4 | Overall strength. |
| Banding | float | 0.0 | 0 .. 16 | Quantises the falloff into this many bands, which keeps a soft light from looking out of place against pixel art. 0 is smooth. |
| Invert | bool | 0 |  | Off draws the light. On draws darkness everywhere except the light, so the object becomes a shadow sheet with a hole in it. |
| Ignore Aspect | bool | 0 |  | On lets the light stretch with the object instead of staying round. |

**How to drive it:** For a torch, cover the frame with a rectangle filled with your darkest colour, apply this with Invert on, and move Centre X and Y to follow the player. For a glowing lamp, use a small rectangle with Invert off and set the object's ink effect to Add.

## Mask

### Alpha Mask

`CyberMushroom/Mask/AlphaMask.*`

Cuts the object out using a second image you supply. Anything you can draw, you can mask with: torn paper edges, a spotlight, a window in a wall, a hand-drawn transition.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Offset X | float | 0.0 | -100 .. 100 | Slides the mask sideways, where 1 is its full width. |
| Offset Y | float | 0.0 | -100 .. 100 | Slides the mask vertically. |
| Scale X | float | 1.0 | 0.01 .. 64 | Stretches the mask horizontally. |
| Scale Y | float | 1.0 | 0.01 .. 64 | Stretches the mask vertically. |
| Channel | int | 0 | 0 .. 4 | Which part of the mask to read: 0 alpha, 1 luminance, 2 red, 3 green, 4 blue. |
| Contrast | float | 1.0 | 0 .. 16 | Hardens the mask around its midpoint. High values turn a soft gradient into a crisp cut. |
| Invert | bool | 0 |  | On keeps what the mask hides and hides what it keeps. |
| Tile | bool | 0 |  | On repeats the mask instead of stretching one copy across the object. |
| Mask Image | image | - |  | The image to mask with. White or opaque keeps the pixel, black or transparent removes it. |

**How to drive it:** Scroll the mask with Offset X and Y to sweep a shape across the object without animating a mask per frame.

> The mask image is stretched across the whole object, so draw it at the object's proportions or it will squash.

### Dissolve

`CyberMushroom/Mask/Dissolve.*`

Eats the image away in random blocks, with a burning edge. Works as a death effect on a sprite and as a scene transition on a layer, and because the blocks are square it stays honest on a pixel grid.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Edge Colour | color | 16777215 (RGB 255, 255, 255) |  | Colour of the band at the dissolve front. |
| Amount | float | 0.0 | 0 .. 1 | 0 is untouched, 1 is completely gone. Animate this. |
| Block Size | float | 2.0 | 1 .. 64 | Size of one dissolve block in texels. 1 is per-pixel static, larger reads as chunks falling away. |
| Edge Width | float | 0.15 | 0 .. 1 | How wide the coloured burning band is. 0 removes it. |
| Seed | float | 0.0 | 0 .. 1000 | Changes which blocks go first. Any two objects with different seeds dissolve differently. |
| Reverse | bool | 0 |  | On makes the object appear instead of disappear as Amount rises. |

**How to drive it:** Animate Amount from 0 to 1. Use Set effect parameter on Seed (any number) so two objects dissolving at once do not pick the same blocks.

### Iris Wipe

`CyberMushroom/Mask/IrisWipe.*`

The shape closing in around the hero at the end of a level. Circle, diamond or square, centred anywhere, opening or closing.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Centre X | float | 0.5 | -1 .. 2 | Centre of the shape across the object. |
| Centre Y | float | 0.5 | -1 .. 2 | Centre of the shape down the object. |
| Radius | float | 0.5 | 0 .. 2 | Size of the shape, where 1 reaches the edge of the object. Animate this. |
| Softness | float | 0.01 | 0 .. 1 | How soft the edge of the shape is. 0 is a hard edge. |
| Shape | int | 0 | 0 .. 2 | 0 circle, 1 diamond, 2 square. |
| Reverse | bool | 0 |  | Off keeps the inside of the shape and hides the outside. On hides the inside, which is what you want on a full-screen cover object. |
| Ignore Aspect | bool | 0 |  | On measures in texture coordinates, so the shape stretches with the object. Off keeps a circle round on a wide screen. |

**How to drive it:** Put a full-screen object filled with your darkest colour on the top layer, apply this, turn Reverse on and animate Radius from 1.5 down to 0 to close the iris on the player. Track the player by animating Centre X and Y.

### Wipe

`CyberMushroom/Mask/Wipe.*`

A straight-edged wipe at any angle, with an optional coloured leading edge. The workhorse scene transition - put it on a full-screen object and animate Amount.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Edge Colour | color | 16777215 (RGB 255, 255, 255) |  | Colour of the band at the leading edge. |
| Amount | float | 0.0 | 0 .. 1 | How far the wipe has travelled. Animate this. |
| Angle | float | 0.0 | 0 .. 360 | Direction the wipe travels, in degrees. |
| Softness | float | 0.02 | 0 .. 1 | How gradual the edge is. 0 is a hard line. |
| Edge Width | float | 0.0 | 0 .. 1 | Width of the coloured leading band. 0 removes it. |
| Reverse | bool | 0 |  | On wipes the object in instead of out. |

**How to drive it:** Amount 0 shows everything, 1 hides everything. Angle 0 wipes left to right, 90 wipes bottom to top.

## Outline

### Drop Shadow

`CyberMushroom/Outline/DropShadow.*`

Casts an offset shadow of the sprite behind itself, in one draw and one object. Lifts HUD cards and text off the background - the same trick the score panel in this repo uses, but free.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Shadow Colour | color | 997391 (RGB 15, 56, 15) |  | Shadow colour. Default is DMG 15,56,15. |
| Offset X | float | 1.0 | -32 .. 32 | How far right the shadow falls, in texels. |
| Offset Y | float | 1.0 | -32 .. 32 | How far down the shadow falls, in texels. |
| Opacity | float | 0.6 | 0 .. 1 | Shadow opacity. |
| Soften | float | 0.0 | 0 .. 16 | Blurs the shadow by averaging four extra taps this far out, in texels. 0 keeps it hard edged, which is the right answer for pixel art. |

> The shadow is drawn inside the object's own image. Leave transparent padding on the side the shadow falls, or it gets cut off.

### Glow

`CyberMushroom/Outline/Glow.*`

A soft halo around the sprite's silhouette, drawn behind it. Unlike Bloom this does not care how bright the sprite is - a pitch black sprite still glows - so it works for magic, pickups and selection states.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Glow Colour | color | 1031323 (RGB 155, 188, 15) |  | Colour of the halo. Default is DMG 155,188,15. |
| Radius | float | 4.0 | 1 .. 32 | How far the halo reaches, in texels. |
| Strength | float | 1.0 | 0 .. 4 | Halo opacity. 0 turns it off. |
| Falloff | float | 1.0 | 0.1 .. 4 | Above 1 the halo hugs the sprite, below 1 it spreads out flat. |

**How to drive it:** Pulse Strength with a sine to make a pickup breathe.

> The halo lives inside the object's image. Leave at least Radius pixels of transparent padding around the art or it will be clipped square.

### Outline

`CyberMushroom/Outline/Outline.*`

Draws a border around the sprite's silhouette. The single most useful effect in a 2D game: it lifts a character off a busy background, marks a selected unit, and flashes an interactable.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Colour | color | 16777215 (RGB 255, 255, 255) |  | Outline colour. |
| Thickness | float | 1.0 | 0 .. 16 | Outline width in texels. |
| Alpha | float | 1.0 | 0 .. 1 | Outline opacity. 0 turns the outline off without removing the effect. |
| Alpha Cutoff | float | 0.5 | 0 .. 1 | How opaque a pixel has to be to count as part of the sprite. Lower it for soft-edged art. |
| 8-Way | bool | 1 |  | On checks the diagonals too, which keeps corners from being clipped. Off is the cheaper 4-way version. |
| Inside | bool | 0 |  | On draws the border just inside the silhouette instead of around it, so the sprite does not grow. |

**How to drive it:** Leave it applied with Alpha at 0 and raise it when the object becomes selectable, so nothing has to be turned on and off.

> The outline is drawn inside the object's own image, so a sprite whose art touches the edge of its frame has nowhere to put it. Leave at least Thickness pixels of transparent padding around the art.

### Silhouette

`CyberMushroom/Outline/Silhouette.*`

Fills the sprite with one flat colour and keeps its shape. Use a second copy of an object with this on it for a cast shadow, a ghost, an enemy seen through a wall, or the white frame of a teleport.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Colour | color | 0 (RGB 0, 0, 0) |  | The flat colour the sprite becomes. |
| Alpha | float | 1.0 | 0 .. 1 | Opacity of the silhouette. |
| Amount | float | 1.0 | 0 .. 1 | Blends between the original sprite and the flat fill. |
| Alpha Cutoff | float | 0.0 | 0 .. 1 | Pixels below this are dropped entirely, which hardens a soft edge into a crisp shape. |

**How to drive it:** For a ground shadow, duplicate the sprite, squash it, set the colour to your darkest palette entry and drop Alpha to about 0.4.

## Retro

### DMG Palette

`CyberMushroom/Retro/DMGPalette.*`

Crushes anything you point it at down to four tones - the original Game Boy screen, by default the same 155/188/15 greens the HUD assets in this repo are drawn on. Optional ordered dithering buys back the gradients four colours cannot hold.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Shade 1 (darkest) | color | 997391 (RGB 15, 56, 15) |  | Darkest of the four tones. Default is DMG 15,56,15. |
| Shade 2 | color | 3170864 (RGB 48, 98, 48) |  | Dark midtone. Default is DMG 48,98,48. |
| Shade 3 | color | 1027211 (RGB 139, 172, 15) |  | Light midtone. Default is DMG 139,172,15. |
| Shade 4 (lightest) | color | 1031323 (RGB 155, 188, 15) |  | Lightest of the four tones. Default is DMG 155,188,15. |
| Brightness | float | 0.0 | -1 .. 1 | Shifts everything up or down the four tones before quantising. Use it to fade a scene to black or white through the palette. |
| Contrast | float | 1.0 | 0 .. 4 | Spreads or squeezes the brightness range before quantising. |
| Dither | float | 0.0 | 0 .. 1 | 0 is hard banding, 1 is full ordered dithering. Around 0.6 reads as shading rather than noise. |
| Coarse Dither | bool | 0 |  | On uses a chunky 2x2 pattern, off uses a finer 4x4. Coarse holds up better once the game is scaled up on a big screen. |
| Amount | float | 1.0 | 0 .. 1 | Blends the palettised image back over the original, for fading the effect in. |

**How to drive it:** Put it on the frame's top layer, or on a fullscreen Active object with "Apply to background" ticked, so the whole scene lands on one palette instead of each sprite separately.

> The dither pattern is locked to the object's texels. If the object is scaled or rotated the pattern scales with it - for a screen-stable grid, apply this to an unscaled fullscreen layer.

### Dither

`CyberMushroom/Retro/Dither.*`

Ordered (Bayer) dithering with an adjustable number of levels. Where Posterize bands, this one trades banding for a woven pattern, the way an artist fakes a gradient with two colours.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Levels | float | 4.0 | 2 .. 32 | Steps per channel after dithering. 2 is one bit per channel. |
| Dither Strength | float | 1.0 | 0 .. 1 | 0 quantises with hard bands, 1 dithers fully. |
| Pattern Scale | float | 1.0 | 1 .. 8 | Size of one dither cell in texels. Raise it if the game is drawn small and scaled up. |
| Coarse Pattern | bool | 0 |  | On uses a 2x2 matrix, off uses 4x4. |
| Luminance Only | bool | 0 |  | On dithers brightness and keeps the hue smooth. Off dithers each channel, which is what a real indexed palette does. |

**How to drive it:** Leave Levels at 4 and Amount at 1 for a period-correct look; raise Levels to 8 or 16 to keep more shading while the pattern still shows.

### LCD Grid

`CyberMushroom/Retro/LCDGrid.*`

The handheld screen itself: a dot-matrix grid with a gap between cells and a tinted backlight. Sits on top of a finished frame and makes it look like it is being read off a panel rather than drawn on one.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Backlight | color | 1031323 (RGB 155, 188, 15) |  | Colour the panel glows. Default is DMG 155,188,15. |
| Cell Size | float | 4.0 | 1 .. 32 | Grid cell size in texels. |
| Gap Width | float | 0.25 | 0 .. 0.9 | How much of each cell is gap rather than lit area. |
| Gap Darkness | float | 0.3 | 0 .. 1 | How dark the gaps go. Past about 0.5 the image starts to disappear at small cell sizes. |
| Backlight Tint | float | 0.0 | 0 .. 1 | Pushes the whole image toward the backlight colour, the way a DMG panel washes everything green. |

**How to drive it:** Apply to a fullscreen layer above everything. Keep Cell Size at your game's pixel scale - if the frame is 160x144 stretched 4x, Cell Size 4 puts one grid cell on one game pixel.

### Palette Ramp

`CyberMushroom/Retro/PaletteLUT.*`

Re-colours by brightness through a palette strip you supply as an image, instead of the four hard-coded stops Gradient Map gives you. Draw a 1-pixel-tall strip of your palette, drop it in, and the whole game wears it.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Ramp Length | float | 4.0 | 2 .. 256 | How many colours across your strip is. Must match the image or the ends will be sampled wrong. |
| Ramp Rows | float | 1.0 | 1 .. 64 | How many palettes are stacked vertically in the image. |
| Row | float | 0.0 | 0 .. 63 | Which row to read. Animate this to swap palettes. |
| Offset | float | 0.0 | -1 .. 1 | Slides every pixel along the ramp before it is looked up. |
| Contrast | float | 1.0 | 0 .. 4 | Spreads the brightness range across the ramp. |
| Amount | float | 1.0 | 0 .. 1 | Blends the re-coloured pixel back over the original. |
| Palette Ramp | image | - |  | The palette strip. Darkest colour on the left, lightest on the right. |

**How to drive it:** Stack several palettes as rows in one image and animate Row to cross the day/night/hurt palettes without loading anything.

> Set the Palette Ramp image's sampler to point filtering (the generated .xml already does) or Fusion will blend between your palette entries and hand you colours that are not in the palette.

### Pixelate

`CyberMushroom/Retro/Pixelate.*`

Snaps the image to a coarser grid. Useful both as a permanent look and as a transition - ramp the block size up to dissolve a scene into squares.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Block Width | float | 4.0 | 1 .. 64 | Block width in texels. 1 leaves the image alone. |
| Block Height | float | 4.0 | 1 .. 64 | Block height in texels. Set it to 1 with a wide block for a horizontal smear. |
| Sample Centre | bool | 1 |  | On samples the middle of each block, which keeps thin features alive. Off samples the corner, which is the cheaper, blockier classic. |

**How to drive it:** Animate Block Size from 1 upward for a "teleport out"; the object is untouched at 1, so you can leave the effect applied all the time.

> Block size is measured in texels of the object's own image, so a scaled object gets scaled blocks.

## Screen

### Bloom

`CyberMushroom/Screen/Bloom.*`

Bright pixels bleed light into their neighbours. One pass, two rings of taps - not a film-grade bloom, but it costs one draw and it makes lamps, coins and explosions feel hot.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Threshold | float | 0.7 | 0 .. 1 | Only pixels brighter than this bleed. |
| Intensity | float | 0.8 | 0 .. 4 | How much light is added back. |
| Radius | float | 4.0 | 1 .. 64 | How far the light spreads, in texels. |
| Tint Strength | float | 0.0 | 0 .. 1 | Pushes the glow toward Glow Colour instead of the colour of the pixel that made it. |
| Glow Colour | color | 16777215 (RGB 255, 255, 255) |  | Colour the glow is pushed toward when Tint Strength is above 0. |

**How to drive it:** Apply to a layer above the scene. If nothing happens, your Threshold is above the brightest pixel in the frame - drop it.

> On an object rather than a layer, the glow stops at the edge of the object's own image. Leave transparent padding around the sprite or add the effect to the layer instead.

### CRT

`CyberMushroom/Screen/CRT.*`

A whole tube in one pass: barrel curvature, scanlines, a shadow mask and a vignette, with the area outside the glass blacked out. Everything can be dialled to zero, so you can keep just the parts you want.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Bezel Colour | color | 0 (RGB 0, 0, 0) |  | What shows outside the curved glass. |
| Curvature | float | 0.15 | 0 .. 1 | How much the picture bows outward. 0 is a flat panel. |
| Scanlines | float | 0.3 | 0 .. 1 | Strength of the horizontal scanlines. |
| Line Spacing | float | 2.0 | 1 .. 16 | Texels from one scanline to the next. |
| Shadow Mask | float | 0.2 | 0 .. 1 | Strength of the RGB stripe mask. Only visible if the image is drawn at 3 or more screen pixels per texel. |
| Vignette | float | 0.3 | 0 .. 1 | Darkening toward the corners. |
| Brightness | float | 1.15 | 0 .. 3 | Lifts the picture back up - scanlines and mask both cost light. |

**How to drive it:** Apply to a layer or to the frame, never to individual sprites - the curvature has to bend the finished picture.

> Curvature reads the image outside its own edges, which do not exist, so the corners are filled with Bezel Colour rather than smeared pixels.

### Chromatic Aberration

`CyberMushroom/Screen/ChromaticAberration.*`

Splits the red and blue channels apart, the way a cheap lens or a composite cable does. A pinch of it sells "screen", a lot of it sells "something is wrong with the machine".

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Strength | float | 1.0 | 0 .. 32 | How far apart the channels are pulled, in texels. |
| Angle | float | 0.0 | 0 .. 360 | Direction of the split in degrees, used when Radial is off. |
| Radial | bool | 1 |  | On splits outward from the centre so the edges of the screen suffer most, which is how a lens behaves. Off splits everything the same direction. |
| Centre Falloff | float | 1.0 | 0 .. 4 | Radial only: how quickly the split fades out toward the middle of the image. |

**How to drive it:** Spike Strength to 3 or 4 for one frame on a hit, then ease it back to 0.5.

### Film Grain

`CyberMushroom/Screen/FilmGrain.*`

Per-pixel noise over the picture. Breaks up flat areas, hides banding left by a small palette, and gives a still screen something to do.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Amount | float | 0.1 | 0 .. 1 | Strength of the noise. |
| Time | float | 0.0 | 0 .. 100000 | Animate this or the grain will not move. |
| Grain Size | float | 1.0 | 1 .. 16 | Size of one grain in texels. |
| Shadows Only | bool | 0 |  | On keeps the grain out of the highlights, which is how real film behaves and stops bright sprites looking dirty. |
| Coloured | bool | 0 |  | On gives each channel its own noise. Off is monochrome grain, which is usually what you want on a limited palette. |

**How to drive it:** Add 0.1 to Time every tick (Always: Set effect parameter "Time" to Time + 0.1) or the grain freezes into a static pattern.

### Glitch

`CyberMushroom/Screen/Glitch.*`

Torn horizontal bands, an RGB split and dropped lines. The corruption effect - good for damage, bad connections, and anything that should feel like the game itself is breaking.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Amount | float | 0.5 | 0 .. 1 | Overall severity. 0 is a clean image. |
| Time | float | 0.0 | 0 .. 100000 | Animate this or the glitch holds one frozen pattern. |
| Band Count | float | 16.0 | 1 .. 128 | How many horizontal slices the image is torn into. |
| Tear Distance | float | 16.0 | 0 .. 128 | How far a torn band slides sideways, in texels. |
| Colour Split | float | 4.0 | 0 .. 64 | How far the red and blue channels come apart, in texels. |
| Dropped Lines | float | 0.1 | 0 .. 1 | Chance a band goes black instead of tearing. |

**How to drive it:** Animate Time every tick and keep Amount at 0 until you want it; at 0 the image passes through untouched.

### Scanlines

`CyberMushroom/Screen/Scanlines.*`

Dark lines across the image, the CRT tell. On its own it is the cheapest way to make clean pixel art look like it came out of a tube.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Line Spacing | float | 2.0 | 1 .. 32 | Texels from one line to the next. 2 gives the classic every-other-line look. |
| Line Width | float | 0.5 | 0 .. 1 | Fraction of the spacing that is dark. |
| Darkness | float | 0.35 | 0 .. 1 | How far the dark lines are pulled down. |
| Softness | float | 0.3 | 0 .. 1 | 0 is a hard edged line, 1 is a smooth sine-like falloff. |
| Offset | float | 0.0 | -64 .. 64 | Slides the lines along. Add a little each tick for a rolling signal. |
| Vertical | bool | 0 |  | On draws the lines vertically instead, for an aperture-grille look. |

**How to drive it:** Apply to a layer (Layer properties, Effect) so it covers the whole frame. Animate Offset to make the lines roll like a badly synced signal.

### Vignette

`CyberMushroom/Screen/Vignette.*`

Darkens the edges so the eye goes to the middle. Subtle at 0.3, a torch-lit cave at 0.9.

| Parameter | Type | Default | Range | What it does |
| --- | --- | --- | --- | --- |
| Edge Colour | color | 0 (RGB 0, 0, 0) |  | What the edges fade toward. Black is the usual answer; the DMG darkest green keeps it on palette. |
| Radius | float | 0.75 | 0 .. 2 | How far from the centre the darkening starts. |
| Softness | float | 0.5 | 0.01 .. 2 | How gradually it falls off. |
